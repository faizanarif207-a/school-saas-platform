School SaaS — Module & Feature Roadmap

Three phases. Phase 1 (MVP) ships first, gets real schools using it, then Phase 2 & 3 build on top of validated usage.

Phase 1 ~10–12 weeks
MVP — Core Operations
Goal: a school can run day-to-day on this — admit students, mark attendance, collect fees, give receipts.
Super Admin Dashboard Core
Create / suspend schools, assign plans, view platform MRR.
School Setup Core
Campuses, classes, sections, subjects, academic year.
Student Admission & Profile Core
Online form, enrollment per year, guardian record.
Attendance Core
Daily class-wise attendance; absent reports.
Fees & Receipts Core
Fee plans, monthly invoices, payment entry, PDF receipts.
Parent Portal (Basic) Core
View child attendance & fee status. Read-only.
Users & Roles Core
Login, RBAC, school_id-based isolation (RLS).
Phase 2 ~6–8 weeks
Academics & Engagement
Goal: keep parents in the loop, digitise exam workflow, and convert walk-in inquiries into students.
Exams & Result Cards New
Marks entry, grading, printable report cards (Urdu/English).
Teacher Attendance New
Staff daily check-in; monthly summary for payroll.
SMS & WhatsApp New
Fee reminders, absent alerts, exam result notifications.
Admission CRM New
Inquiry → follow-up → conversion to student. Source tracking.
Reports & Exports New
Excel / PDF exports for accounts, attendance, results.
Phase 3 ~8–10 weeks
Operations & Scale
Goal: add revenue streams, scale to multi-campus, and reduce manual work for big schools.
Payroll & HR Advanced
Salary, leave, payslips linked to attendance.
Library & Transport Advanced
Book issue/return, transport routes & fees.
Canteen POS Advanced
Cashier billing, stock, daily sales reports.
Online Payments Advanced
JazzCash, Easypaisa, bank transfer via gateway.
Biometric Integration Advanced
Thumb / face scanner API for staff & students.
Mobile App (PWA) Advanced
Parent app: view reports, pay fees, get alerts.
Multi-Campus Reports Advanced
Consolidated views across all branches of a school.
Sequencing principle: Each phase unlocks the next set of chargeable features. Phase 1 = "school can run". Phase 2 = "school can grow". Phase 3 = "school can scale". Pricing tiers (next diagram) gate which phase-2 / phase-3 modules a school gets based on plan.
