Tenant Isolation Rule
Every database row carries school_id. Row-Level Security (RLS) guarantees School A can never see School B's data.
Tech Stack Layers
1. Presentation Layer (Frontend)
React UI rendered by Next.js App Router, Tailwind CSS, shadcn/ui components
Next.js 16 React 19 Tailwind shadcn/ui
2. Application Layer (Backend)
Server Actions & API routes handle business logic, permissions, billing & PDF generation
Server Actions API Routes TypeScript
3. Auth & Security Layer
Supabase Auth for login; role-based access (Super / School / Teacher / Parent); RLS for tenant isolation
Supabase Auth RBAC Row Level Security
4. Data Layer (Database)
PostgreSQL stores all schools, students, fees, attendance. Prisma ORM for safe queries.
PostgreSQL Supabase DB Prisma ORM
5. External Services Layer
SMS / WhatsApp for parents, email for invites, file storage for receipts, payments for subscriptions
Twilio / SMS Resend Supabase Storage JazzCash / Easypaisa
6. Hosting & Monitoring Layer
Vercel hosts the Next.js app (auto-deploy from GitHub). Sentry tracks errors in production.
Vercel GitHub Sentry
